# Contributing

Start with the repository's README for its purpose, setup and validation commands. Follow any repository-specific CONTRIBUTING.md and AGENTS.md instructions.

1. Open an issue for a substantial change so its scope can be discussed first.
2. Create a focused branch, or a fork for an open-source repository.
3. Explain the problem and resulting behavior in your pull request. Include the checks you ran and screenshots for interface changes.
4. Keep unrelated changes separate and resolve review comments before merging.

Never include credentials, private customer data or production exports in issues, commits or screenshots. Report vulnerabilities through the [security policy](https://github.com/Codara-Solutions/.github/blob/main/SECURITY.md), not a public issue.

A public repository's own license governs its contributions and use. These guidelines do not grant a license to any private repository.
